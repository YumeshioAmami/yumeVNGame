# Core Style Guide

This is the original fallback style guide used when no external dataset plugin is active.

1. Every scene must change the situation, a relationship, or a character's understanding.
2. Do not explain the theme; make a choice carry it.
3. Foreshadow with concrete objects, lines, or actions, not abstract concepts.
4. Give each character a distinct way of avoiding the truth.
5. Let silence, weather, and negative space do narrative work.
6. A choice should have a cost that remains after the scene ends.
7. Reveals should make earlier details mean something new.
8. Endings should land on consequence, not explanation.
9. Avoid overlored exposition; let conflict carry world information.
10. Do not imitate another work's sentences. Learn its pacing and structure instead.
