# Dataset Notice

## Plot summaries

The `summary_zh` fields in `works.jsonl` were extracted from public Chinese Wikipedia articles.

- Source license: CC BY-SA
- Each record keeps its `summary_source` and `source_urls`
- Modifications: whitespace normalization, section selection, and truncation for style-reference use

If you redistribute this dataset, keep the source URLs and this notice.

## Editorial metadata

The following fields are editorial work by the yumeVNGame contributors:

- `genres`
- `themes`
- `tags`
- `narrative_devices`
- `pacing_notes`
- `character_notes`
- `fallback_summary` (when present)

They are provided for research, prompting, and structural analysis.

## Not included

- Game executables or archives
- Full commercial scripts
- Commercial sprites, CG, music, or voice files

This dataset is not a substitute for the original works. If you enjoy a title, support the official release.
