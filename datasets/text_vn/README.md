# yumeVNGame Text VN Dataset v0.1

这是一个用于 **风格参考、结构分析、Few-shot、RAG 和评测** 的视觉小说文本数据集。

## 收录内容

- 作品元数据：中文名、原名、开发商、年份、类型、主题、标签；
- 剧情摘要：来自公开百科条目的剧情 / 故事章节，保留来源链接；
- 结构分析：叙事装置、节奏、人物声音、常见结构；
- 风格笔记：`style_notes.md`，用于给故事导演提供“怎么写得像一部好 VN”的参考。

## 不收录内容

- 不打包游戏本体；
- 不打包完整商业游戏脚本；
- 不打包受版权保护的立绘、音乐、语音、CG；
- 不把摘要伪装成原文。

## 使用边界

剧情摘要来自公开百科（主要是中文 Wikipedia，CC BY-SA）。  
元数据与结构分析是本项目编辑整理的内容。  
数据集只用于研究、风格参考和模型提示，不用于重新分发商业游戏内容。

如果你要扩展数据集：

1. 优先使用公开百科、官方简介、开发者访谈、公开 Demo；
2. 每条记录保留 `source_urls` 和 `license_note`；
3. 不要直接抓取完整游戏脚本；
4. 不要提交游戏资源文件。

## 文件

- `manifest.json`：数据集版本、来源策略、字段说明；
- `works.jsonl`：每行一部作品；
- `style_notes.md`：写作与结构参考；
- `raw/`：本地抓取的百科纯文本（`.gitignore` 忽略，不提交）。

## 重新生成

```bash
python scripts/build_text_dataset.py
```
