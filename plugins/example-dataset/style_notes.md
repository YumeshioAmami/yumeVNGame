# 视觉小说风格与结构笔记

> 这不是原文库，也不是模仿清单。它只记录“这些作品为什么成立”的结构经验，供故事导演做原创故事时参考。

## 1. 命运石之门

- 慢热不是缺点，前提是日常段落在埋线：人物关系、玩笑、习惯、物件都要在后面回收。
- 中二外壳是人物保护色，真正的情绪在壳裂开时才有效。
- 世界线收束制造“越努力越接近悲剧”的压迫感。
- 反转不是靠新设定硬拐，而是让前文已经出现过的细节获得新意义。

## 2. CLANNAD

- 日常积累是情绪本金。没有足够长的日常，后面的失去就没有重量。
- 家庭不是背景板，而是人物行动的根。
- 奇迹要建立在“已经付出代价”的基础上，不能当万能解。
- 路线之间可以共享世界观，但每条路线要有自己的中心问题。

## 3. 素晴日

- 不可靠叙述要让读者先相信，再怀疑，最后重新理解。
- 多视角不是重复同一件事，而是让同一件事在不同人物眼里变成不同伦理问题。
- 哲学引用不能代替戏剧，必须落到人物的选择和代价上。
- 认知崩塌要有节奏：先小裂缝，再结构性崩坏。

## 4. 沙耶之歌

- 感官错位可以制造极端的亲密与恐怖并存。
- 短篇要压缩：少人物、少地点、强概念、强结局。
- 禁忌恋爱不是靠猎奇成立，而是靠“只有她能理解我”的孤独。
- 结局要让玩家承担选择的伦理后果，而不是只给一个惊吓。

## 5. 缘之空

- 乡村空间适合写孤独：安静、重复、没有出口。
- 禁忌关系的力量来自外部压力和内部依恋的拉扯。
- 多路线不是“攻略角色”，而是不同孤独形态的展开。
- 日常场景要有季节、声音、气味，不能只写对话。

## 6. 千恋＊万花

- 和风日常的关键是“生活质感”：祭典、食物、神社、雨、木廊。
- 萌系节奏不等于没有冲突；冲突可以小而具体。
- 路线分工要清楚：每条线解决不同的人物核心问题。
- 轻喜剧段落要服务于人物关系，而不是单纯拖时长。

## 7. 白色相簿2

- 三角关系的关键不是“谁赢”，而是三个人都在做自己认为正确的事。
- 音乐场景可以作为关系的温度计：同一首歌在不同阶段有不同含义。
- 道德重量来自“伤害了谁”，而不是来自旁白说教。
- 选择要有不可逆的代价。

## 8. Fate/stay night

- 多路线可以共享同一场战争，但每条路线回答不同问题。
- 设定密度高时，要用人物冲突来承载信息，而不是一次性解释。
- 理想主义必须被现实反复撞击，才有戏剧性。
- 战斗不是数值，而是理念、代价和身份的碰撞。

## 9. 寒蝉鸣泣之时

- 轮回结构要让每一轮都提供新信息，而不是重复。
- 信任崩塌比怪物更恐怖。
- 解谜篇要能把前面的“不合理”重新解释成“合理”。
- 乡村封闭空间适合制造信息差和集体沉默。

## 10. 月姬

- 多路线可以探索同一人物的不同欲望侧面。
- 吸血鬼 / 死亡题材要有感官细节：冷、铁锈、夜色、呼吸。
- 主角的能力必须有代价和限制。
- 恋爱与恐怖可以共存，但要让它们互相加压。

## 11. Ever17

- 叙述性诡计要建立在视角限制上，而不是欺骗读者。
- 密室 / 孤岛结构适合压缩人物关系。
- 多视角要提供不同信息，而不是重复同一视角。
- 真相揭示后，前文必须仍然成立。

## 12. 428 被封锁的涩谷

- 群像交错的关键是“因果链”：一个人的小选择改变另一个人的命运。
- 时间压力可以替代传统章节结构。
- 多主角要有不同的语言节奏和信息渠道。
- 选择不要都通向大结局，有些只改变一个细节，但那个细节会回来。

## 13. Key 系作品（AIR / Kanon / Little Busters!）

- 季节和天气是情绪结构，不只是背景。
- 记忆、约定、告别是核心母题。
- 日常喜剧要真有趣，不能只是为催泪做铺垫。
- 奇迹必须与“接受失去”同时存在。

## 14. Muv-Luv Alternative

- 平行世界 / 时间跳跃要让主角付出心理代价。
- 战争题材要有具体战术和具体死亡，不能只写宏大。
- 绝望要一层层加码，但每层都要给人物一个选择。
- 机甲是人物关系的延伸，不是独立玩具展示。

## 15. 灰色的果实

- 孤岛 / 学校可以作为创伤的封闭容器。
- 每个角色的黑暗过去要有不同形态：暴力、控制、羞耻、依赖。
- 主角的“万能”必须有空洞，否则会失去张力。
- 救赎不是治愈一切，而是让人愿意继续活。

## 16. 通用写作规则

1. 先定中心问题，再定场景。每场戏都要改变局势、关系或认知。
2. 不要让角色解释主题；让选择承担主题。
3. 伏笔要具体：一个物件、一句话、一个动作，而不是抽象概念。
4. 每条路线至少有一个“如果当时不这样选”的遗憾。
5. 对话要有潜台词，人物不能都像作者。
6. 视觉小说要留白：画面、停顿、环境音、没有说出口的话。
7. 结局不是“解释完”，而是“代价发生了”。
8. 不模仿具体句子，只学习节奏、结构和人物声音。
